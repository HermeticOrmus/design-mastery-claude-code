# Kintsugi ledger: design-mastery-claude-code

Kintsugi mends a broken bowl with gold, so the repair is the part you look at. Here it means every crack we find in this plugin is written down with its evidence, sealed with a fix you can check, and kept in this table instead of being patched quietly.

The hallmarked rows shipped in [v1.1.0](https://github.com/HermeticOrmus/design-mastery-claude-code/releases/tag/v1.1.0) through [#2](https://github.com/HermeticOrmus/design-mastery-claude-code/pull/2), which was verified by installing the plugin from GitHub into a clean config. For this ledger the released plugin was installed from GitHub into a clean Claude Code config again: 1 of 1 enabled. Sealed rows are fixed in an open pull request; open rows are cracks the repo already tracks, and the Tracker column says where to pick one up.

Grades: **hairline** is copy or cosmetic, **fracture** is wrong behavior with a workaround, **break** means it did not work or broke a safety promise.

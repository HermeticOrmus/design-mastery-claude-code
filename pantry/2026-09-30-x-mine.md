# X mine: design-mastery-claude-code competitors

## How this fills

1. Take the top 5 to 8 names from the latest competitor map.
2. Search X for praise and complaints tied to **named matrix capabilities** (reliability, cost, DX, permissions, memory, multi-agent, verify), not brand vibes alone.
3. Fetch primary posts; quote short snippets with `x.com` links. **Never invent engagement counts or sentiment %.**
4. Save as `YYYY-MM-DD-x-mine.md` (keep this TEMPLATE).

How the text was fetched: WebSearch with `site:x.com` found the posts. WebFetch of x.com returned HTTP 402, so each post's text was read from the public mirror `https://api.fxtwitter.com/status/<id>`, which returns the post as posted. Every snippet below is copied from that response; the link is the post on x.com. Translations in brackets are ours. Theme names match the rows of the capabilities matrix in [2026-09-30-competitor-map.md](2026-09-30-competitor-map.md). No engagement counts are recorded.
